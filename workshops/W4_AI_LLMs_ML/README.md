# Week 4 - AI Literacy: Understanding and Using Large Language Models

Last week we made our project reproducible and citable. This week we zoom out to look at one of the most significant shifts in how researchers work right now: AI, and in particular large language models (LLMs). Rather than a technical deep-dive, today is about building enough understanding to use these tools well — and to know when not to.

## Learning Objectives

By the end of today, you can:
- explain what a large language model is and how it works in broad terms
- describe the main uses and benefits of LLMs for research
- identify the key risks and limitations — and why these matter especially in a scientific context
- apply practical techniques that reliably improve LLM outputs
- critically evaluate an LLM response rather than just accepting it

## Introduction

### What is machine learning?

Today starts with something that might feel like a detour: a quick look at how machine learning actually works. Not because you need to become an ML expert, but because understanding the basic idea — how a model learns from data, what "performance" means, and why it can fail on new examples — will make everything that follows about LLMs make more sense.

### Discuss responses

There's a good chance people in this room are already using LLMs — for writing, for code, for summarising papers. That's fine. The goal today isn't to persuade you to use them or not, but to make sure that when you do, you're doing it in a way that's informed, critical, and appropriate.

One framing that's worth keeping in mind all day: **the ability to evaluate AI-generated outputs is more important than the ability to generate them.**
