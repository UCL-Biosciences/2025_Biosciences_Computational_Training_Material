# Intro to Python
Why code?

Ask participants on menti:
-	What does data analysis mean to you?
-	Why would someone learn to code?
-	How could code improve your work (life)?

Some examples
-	**Repetition is free**. If you have 50 files to process the same way, code does it in seconds; a GUI makes you repeat the same clicks 50 times, and 50th time you'll make a mistake you won't notice.
-	**It's redoable.** Reviewer asks you to redo the analysis excluding one outlier, or with a different threshold? In code that's a one-line change and rerun. In a GUI you're starting most of it over, and hoping you remember every click you made three months ago.
-	**You can see and check your own steps.** A script is a record of exactly what you did to your data. A trail of Excel clicks is not — which becomes a real problem when you can't remember why a spreadsheet looks the way it does, or someone asks you to justify a step.
-	**It scales**. GUI tools tend to quietly break or become painful past a certain dataset size; code is more flexible with respect to data size.
